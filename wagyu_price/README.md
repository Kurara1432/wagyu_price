# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
    ・リモートリポジトリ
        チーム開発においての大元になるもの、ここにそれぞれがローカルリポジトリで書いたコードとかをマージする
    ・ローカルリポジトリ
        それぞれが実際にコード等を書いて、変更などをしたりするリポジトリ、これをリモートリポジトリにマージとかする


## プッシュとマージの違いは何でしょうか？
    ・push
        ローカルリポジトリで行った変更を、リモートリポジトリに反映させること
    ・merge
        違うブランチの変更を他のブランチにも統合すること


## コミットとプッシュの違い
    ・コミット
        ローカルリポジトリにて変更した内容を記録すること
    ・push
        ローカルリポジトリで行った変更を、リモートリポジトリに反映させること


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
    ・ほかの人が見て、何のためにコミットしたのかを分かりやすく書く


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
    ・ローカルでマージ
        自分の判断でマージできるため、即マージできる
    ・プルリクエスト
        権限付与した人にマージをしてもら方法、その際にgit hub上で変更点などをチェックしてもらえる


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
    ・コンフリクトした際に同じ箇所を変更したもののコードを確認し、相談したうえで下記の二つの方法がある
        ・同じ箇所を変更したものの誰かのものをマージする
        ・それぞれの変更点を把握し、それぞれの変更点から良いとこ取りをする
